# Showzin Portal

Portal de descoberta de shows e eventos com blog no domínio principal, preparado para deploy na Vercel.

## Stack
- Next.js (App Router)
- TypeScript

## Estrutura
- `app/` rotas públicas + admin MVP
- `components/` componentes de UI reutilizáveis
- `lib/` dados mock e utilitários

## Rodar localmente
```bash
npm install
npm run dev
```
